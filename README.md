# 도시대기측정소 점검 — 관리자 지도 화면

압축을 푼 뒤 **파일들과 `assets` 폴더를 함께** 기존 GitHub Pages 저장소의 같은 위치에 업로드하세요. `admin.html`과 `assets` 폴더가 나란히 있어야 합니다. 기존에 다른 용도로 사용하는 파일은 삭제할 필요가 없습니다.

이번 변경은 관리자용 `admin.html`, 지도 자료 `assets/`, 공통 캐시 `sw.js`입니다. 사용자용 `user.html`, 기존 아이콘, 시작 화면, manifest 파일은 이전 배포본 그대로 포함했습니다.

관리자 홈 → **출장 경로**에서 사용합니다.

- 지도 점을 눌러 측정소를 선택합니다. 숫자 묶음은 누르면 확대됩니다.
- 시군 영역을 누르면 해당 지역의 측정소를 일괄 선택할 수 있습니다.
- **계획 파일 불러오기**에서 연간 출장계획 JSON을 선택한 다음 출장 날짜를 고릅니다.
- 계획에 `춘천(2)`처럼 일부 측정소만 지정되어 있으면 직접 선택합니다. 날짜와 메모가 다르거나 다른 출장에도 선택한 측정소가 있으면 안내합니다.
- **방문 순서 추천** 후 화살표로 순서를 바꾸거나 1·2일차 사이로 옮깁니다.
- 숙박 장소는 지도에서 지정합니다. **도로지도**는 온라인에서 켤 수 있습니다.
- 일정은 현재 브라우저에 임시저장됩니다. 불러온 출장계획은 GitHub나 Firebase에 전송하지 않습니다.

점선과 번호는 **직선거리를 기준으로 추천한 방문 순서**입니다. 실제 도로 경로·교통·점검시간은 반영하지 않습니다. 실제 길찾기는 네이버지도 앱에서 확인하세요.

배포 후 기존 앱을 닫고 다시 열거나 새로고침해 주세요. 기본 측정소 지도는 새 버전을 온라인에서 한 번 연 뒤 오프라인에서도 사용할 수 있습니다. 데이터 출처와 라이선스는 `assets/map-sources.txt`, `assets/leaflet/LICENSE`에 있습니다.
