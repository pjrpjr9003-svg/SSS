지도 데이터와 사용 범위

측정소 위치
- 사용자가 제공한 측정망상세현황_20260806.xlsx의 Sheet1.
- 도시대기·도로변대기 측정망에 속하는 앱의 27개 측정소를 코드로 대조했습니다.
- DM X열을 위도, DM Y열을 경도로 사용했습니다. 좌표는 6자리로 반올림/절삭했습니다.
- 원본 점검표 데이터와 측정소 코드, 사용자용 화면은 변경하지 않았습니다.

행정구역 경계
- 통계청 2018년 시군구 경계. 현재 행정경계를 보증하지 않는 위치 안내용 지도입니다.
- 출처: https://github.com/southkorea/southkorea-maps
- 원본: kostat/2018/json/skorea-municipalities-2018-geo.json
- 출처 저장소의 통계청 데이터 사용 조건: 공유 및 변경 가능. 배경 지도용으로 단순화했습니다.
- 강원 지역 18개 시군은 원본 code 32로 시작하는 구역입니다.

보건환경연구원 출발점
- 공식 찾아오시는길: https://gihe.gwd.go.kr/contents.do?cid=2985bc622420459987aca90f52f3a404
- 해당 페이지의 본원 지도: https://t1.kakaocdn.net/roughmap/rfjn.json
- 장소 좌표 WCONGNAMUL을 2.5로 나누어 EPSG:5181, 이후 WGS84로 변환했습니다.
- 변환 근거: https://devtalk.kakao.com/t/drawing-library/139708

지도 라이브러리
- Leaflet 1.9.4 (BSD 2-Clause). 라이선스: leaflet/LICENSE
- https://leafletjs.com/reference.html
- 지도와 경계 자료를 로컬 파일로 제공하므로 지도 API 키나 외부 타일 요청은 필요하지 않습니다.
- 선택 기능 '도로지도'를 켜면 OpenStreetMap 도로 타일을 온라인으로 표시합니다.
- https://www.openstreetmap.org/copyright / https://operations.osmfoundation.org/policies/tiles/
- 도로 타일은 오프라인 저장·대량 다운로드하지 않으며, 기본 브라우저 HTTP 캐시 정책을 따릅니다.

방문 순서
- 직선거리(대권거리)를 바탕으로 다중 시작점 최근접 탐색과 2-opt를 사용합니다.
- 1박2일은 두 날짜의 직선 이동량과 총 이동량을 비교해 분할합니다.
- 실제 도로 경로, 교통량, 고도, 점검 소요시간을 반영한 최적 경로가 아닙니다.
- 지도 점선은 방문 순서입니다. 실제 길찾기는 네이버지도 앱에서 확인합니다.
- URL Scheme: https://guide.ncloud-docs.com/docs/maps-url-scheme
- 숙박업소가 지정되지 않으면 선택한 지역의 측정소 위치를 지역 기준점으로 표시합니다.

출장계획 파일
- 관리자 화면의 '계획 파일 불러오기'에서 연간 출장계획 JSON을 읽을 수 있습니다.
- 계획의 내용과 수정한 방문 순서는 현재 브라우저 localStorage에만 보관합니다.
- GitHub 업로드 패키지에 개인 출장계획, 이름, 출장 날짜를 포함하지 않았습니다.
